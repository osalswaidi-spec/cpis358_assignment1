About The Project

OctoDrives is a smart web platform that turns the traditional car test drive into a fully digital experience. Customers can browse cars, verify their National ID using OCR, and book a test drive online.

It replaces paper forms, manual ID checks, and phone calls with one fast connected system for customers and dealerships.

Key Features

  • Real-time vehicle availability
  • Automated National ID verification
  • Secure Tamm authorization
  • Contactless key pickup using Smart Lockers
  • Bilingual interface (English & Arabic)

How It Works

  1. Create an account or log in.
  2. Pick a branch and a vehicle.
  3. Upload your National ID.
  4. Confirm the booking and get a code.
  5. Pick the key from the Smart Locker and drive.
